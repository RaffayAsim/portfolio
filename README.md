# Raffay Asim — Portfolio

Premium dark cinematic portfolio for Raffay Asim — AI Automation Architect | Full-Stack Vibe Coder.

## Stack

- Next.js 15 (App Router)
- Tailwind CSS
- Framer Motion
- Lenis (smooth scroll)

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
