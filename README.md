## Deploy on Vercel

1. Push this repo to GitHub (e.g. RaffayAsim/portfolio).
2. Go to vercel.com/new and import the repository.
3. Framework preset: Next.js (auto-detected). Leave env vars empty.
4. Click Deploy. Vercel will build and give you a production URL.
5. Optional: add a custom domain under Project → Settings → Domains.

CLI alternative: use the Vercel CLI (`vercel` then `vercel --prod`).
